# Wanderly - Travel Blog Application

A responsive travel blog interface built with HTML, CSS, and JavaScript.
This is the front-end project for Module 1.

## Pages

- **Home**: hero section and a responsive grid of travel story cards
- **Login**: form with validation
- **Register**: form with validation and password confirmation
- **Create Blog**: form to write and publish a new story
- **Dashboard**: lists your stories, shows a story count, and lets you delete posts

## Features

- Responsive layout for mobile, tablet, and desktop using CSS Grid, Flexbox, and media queries
- Client-side form validation with clear error messages
- Stories saved in the browser with `localStorage`
- Shared navbar and footer with an active-link highlight
- Smooth scrolling and a dynamic footer year

## Technologies

- HTML5
- CSS3 (variables, Grid, Flexbox)
- JavaScript (DOM manipulation, events, localStorage)

## How to Run

1. Clone the repository:
   `git clone https://github.com/hemadharshinis3-cmd/blogapp-frontend.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
